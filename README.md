# Поиск торрентов по нескольким названиям для Lampa

Версия 0.1.0. Отдельный JavaScript-плагин для официальной Lampa. Пересборка APK, платная подписка и постоянно включённый ПК не требуются, если файл плагина доступен по постоянному URL.

## Поведение

При открытии источника «Торренты» в карточке выполняются отдельные запросы: название карточки, один другой русский вариант, английское и оригинальное названия, один существующий вариант латиницей для японского аниме. Всего до пяти разных запросов. Набор зависит от метаданных; плагин не придумывает перевод или транслитерацию. Недостающее английское название запрашивается через уже настроенный в Lampa TMDB API.

Поиск использует существующие настройки парсеров. При выборе двух адресов Lampa обращается к обоим в каждом раунде. Раунды идут последовательно, минимум через две секунды после начала предыдущего. Общий бюджет — 40 секунд, ожидание одного раунда — до 16 секунд. При медленных парсерах не все названия успеют провериться. Повторных попыток автоматически нет. Отмена и уход из карточки подавляют результаты предыдущего поиска; уже отправленный HTTP-запрос штатная Lampa может физически не прервать.

Дубли объединяются по torrent info hash, в том числе при разном наборе трекеров в magnet и кодировках hex/base32. Исторический `item.hash` Lampa не меняется. Без info hash используется ссылка либо название/размер/трекер: в таком случае абсолютное отсутствие дублей не гарантируется. Сохраняются фильтры года, типа, категорий и суффикс сезона `S01`.

Ручное «Уточнить» и свободный текстовый поиск остаются обычными одиночными запросами. Полностью успешные результаты кэшируются в оперативной памяти на 10 минут, до 12 поисков, до 2000 раздач в ответе; перезапуск очищает кэш. Ошибки и неполные поиски не кэшируются. Штатный парсер может скрыть отказ одного сервера, если второй ответил успешно — расширение не может определить такую ошибку по его публичному ответу.

## Установка и отключение

1. Постоянный адрес: [plugin.js](https://andrewslastenko.github.io/lampa-multititle-search/plugin.js). Его также можно разместить на собственном HTTPS-хостинге.
2. Lampa → Настройки → Расширения → Добавить плагин → указанный URL.
3. Перезапустить Lampa. В настройках появится «Поиск по названиям» с одним переключателем.
4. Открыть карточку → Смотреть → Торренты. При нескольких названиях появится короткое уведомление.

Отключение: Настройки → Поиск по названиям → выключить переключатель. Полное удаление: удалить соответствующий URL в расширениях и перезапустить Lampa. Данные каталогов, настройки TorrServer и файлы видео плагин не меняет. Дополнительных аккаунтов, аналитики и фонового сервиса нет.

## Проверки

- `node --test test/plugin.test.js`: 15 успешных тестов; `node --check plugin.js`: синтаксис корректен.
- Независимое ревью: замечания к ключу кэша и выбору латинских аниме-названий исправлены; повторная проверка без оставшихся замечаний.
- Проверено подключение расширения к официальному Android-клиенту Lampa и автоматическое объединение результатов по нескольким названиям.
- Наличие записи не подтверждает её подлинность, качество, озвучку, HDR или доступность пиров.

## Исходный API

Интеграция проверена по [Parser](https://github.com/yumata/lampa-source/blob/main/src/core/api/sources/parser.js), [TMDB](https://github.com/yumata/lampa-source/blob/main/src/core/api/sources/tmdb.js) и [загрузчику расширений Lampa](https://github.com/yumata/lampa-source/blob/main/src/core/plugins.js).

Изменение API Lampa или поведение внешних парсеров может потребовать обновления плагина. Поиск не гарантирует наличие любого фильма или полного списка релизов.

## Дополнение: автоматический выбор TorrServer

Отдельное необязательное расширение [torrserver-auto.js](https://andrewslastenko.github.io/lampa-multititle-search/torrserver-auto.js) выбирает доступный сервер перед каждым новым открытием торрента. Оно не требуется для поиска по нескольким названиям.

В настройках TorrServer Lampa укажите сервер 1 как предпочтительный, а сервер 2 как резервный. Например, первым может быть домашний ПК, вторым — локальный сервер приставки. Плагин использует только уже введённые адреса и штатные параметры авторизации, не содержит адресов по умолчанию и не изменяет их. На Android нужен включённый внутренний JavaScript-клиент TorrServer.

Проверка каждого адреса ограничена 1,5 секунды: отвечает сервер1 — используется он; иначе проверяется сервер2. Это работает при выборе новой раздачи в карточке и при загрузке библиотеки торрентов. Если оба не отвечают, операция отменяется с уведомлением. Повторная проверка выполняется при следующей операции, поэтому включившийся ПК снова получает приоритет. Уход на другую страницу отменяет ожидающий запуск.

При открытии сохранённого торрента сначала проверяется, что его хеш действительно есть на выбранном для библиотеки сервере, затем — на другом. Поэтому включившийся ПК не перехватывает запись из локальной библиотеки, которой у него нет. Если запись нигде недоступна, плагин предлагает открыть карточку и выбрать раздачу заново. Библиотеки двух серверов остаются раздельными.

В настройках TorrServer появляется переключатель «Автовыбор TorrServer». При его отключении сохраняется штатный ручной выбор. Удаление расширения с перезапуском также возвращает обычное поведение. Поля адресов остаются настроенными.

Работающий плеер продолжает использовать выбранный URL. При выключении или засыпании сервера посреди фильма потребуется заново открыть торрент; бесшовного переноса буфера и сохранённых списков между серверами нет. Сам плагин не включает ПК, не устанавливает TorrServer и не переключает Ethernet/Wi-Fi.

Проверки обоих расширений: `node --test test/plugin.test.js test/torrserver-auto.test.js` (37 тестов), синтаксис обоих JS-файлов, независимое ревью. Публичный код и тесты не содержат настроек домашних устройств.

## Дополнение: прогресс YummyAnime во внешнем Android-плеере

[yummy-native-progress.js](https://andrewslastenko.github.io/lampa-multititle-search/yummy-native-progress.js) добавляет тайм-код в запуск внешнего Android-плеера из YummyAnime и записывает возвращённую позицию в локальную историю аниме. Нужны официальный Android-клиент Lampa, YummyAnime и плеер, возвращающий позицию (например, JustPlayer). URL устанавливается как обычное расширение, затем Lampa перезапускается.

Ключ позиции зависит от аниме, номера серии и варианта озвучки, а не от временной ссылки на поток. Сохраняются выбранная озвучка и остальные поля истории. Поздний результат предыдущей серии не перезаписывает уже выбранную новую серию или другую озвучку. Сброс прогресса в YummyAnime также сбрасывает позицию для внешнего плеера. Обычные фильмы и запуски с собственным тайм-кодом проходят без изменений. Облачный аккаунт, сетевые запросы и дополнительные разрешения расширению не нужны.

Плеер должен завершаться штатно с возвратом в Lampa. Плагин не добавляет отсутствующие серии, не восстанавливает недоступные источники и не реализует автоматическое разрешение следующего потока. Для удаления достаточно убрать URL расширения и перезапустить Lampa; записанная история остаётся.

Все три расширения: `node --test test/plugin.test.js test/torrserver-auto.test.js test/yummy-native-progress.test.js` (50 тестов).
