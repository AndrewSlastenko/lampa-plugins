# Динамический подбор озвучки и источника BWA

Статус: согласовано пользователем 7 ноября 2026 года. Текущая опубликованная версия Source Auto — 0.1.3; новое поведение предназначено для следующей версии.

## Поведение

Собирать все озвучки с пригодными потоками из ответов проверяемых источников. Список известных студий задаёт предпочтения для автоматического выбора, но больше не ограничивает результаты поиска.

Сначала проверять сохранённые источник и озвучку для конкретной серии. Рабочий сохранённый выбор сохранять. Если он недоступен, искать ту же озвучку в других проверяемых источниках. Среди подходящих вариантов выбирать качество, сохраняя порядок «озвучка, затем разрешение».

Если нужная или знакомая озвучка не найдена, показывать список реально найденных озвучек, включая незнакомые. У каждого варианта показывать источник и доступное качество. Выбор пользователя запоминать для этого произведения. Незнакомую озвучку автоматически не подставлять в этом случае: это конкретизация запроса пользователя о списке для выбора.

## Сопоставление названий

Для поиска нормализовать регистр, пробелы, пунктуацию, начальную нумерацию и явные служебные обозначения языка или типа перевода. Сопоставлять кириллическое и латинское написание по консервативным правилам: например, «01. Дубляж. ТВ-3 (RUS)» и «TV3».

Номера внутри названия сохранять. Общие подписи без студии, например «Дубляж» или «Русский», не объединять между источниками как доказанно одну озвучку. Не использовать расстояние редактирования для автоматического объединения похожих названий студий. Неоднозначные совпадения оставлять отдельными вариантами.

Исходные название и поле raw сохранять. Нормализация используется для сопоставления, а запрос и воспроизведение — только с исходным raw, группой качеств и URL выбранного источника. Общего идентификатора студии между источниками в используемом контракте BWA нет.

## Подход

Использовать исходные значения BWA вместе с консервативным сопоставлением названий. Только идентификаторов источника недостаточно для сравнения разных источников; только текстового сравнения недостаточно для корректного запроса потока.

Стартовые предпочтения студий из существующих настроек и пользовательских правил остаются. Они определяют порядок выбора, а не право неизвестной озвучки появиться в результатах. Дополнительный редактор предпочтений и внешняя служба распознавания в эту доработку не входят.

## Ограничения и проверки

Сохранить отмену устаревших запросов, скрытые и платные источники, ограничения быстрого и полного поиска. При неполной проверке сообщать об отсутствии только в проверенных источниках и оставлять доступ к полному поиску.

Проверить варианты ТВ-3/TV3, нумерацию и язык в подписи, незнакомые студии в списке, неоднозначные общие подписи, сохранение источника и raw при выборе, сортировку качества внутри озвучки, переход к другому источнику с той же озвучкой, отмену и совместную работу с series-native.

Изменение не гарантирует работоспособность CDN по одному наличию URL в API и не исправляет неподтверждённое повреждение картинки в декодере.
